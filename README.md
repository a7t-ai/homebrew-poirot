# Homebrew Tap for Poirot

Native macOS companion for [Claude Code](https://github.com/a7t-ai/poirot).

## Install

```bash
brew tap a7t-ai/poirot
brew install --cask poirot
```

If you have `HOMEBREW_REQUIRE_TAP_TRUST` enabled, trust the tap first:

```bash
brew trust a7t-ai/poirot
```

## Update

```bash
brew upgrade --cask poirot
```
